# Security Policy

## Supported Versions

Only the current release line is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report vulnerabilities privately to [muralivijayagiri1@gmail.com](mailto:muralivijayagiri1@gmail.com). Include steps to reproduce the issue, the affected URL or component, and the potential impact.

Do not open a public issue for an undisclosed vulnerability; a fix will be prepared before public disclosure.
